# 🤖 ربات جرئت یا حقیقت برای بله

ربات بازی جرئت یا حقیقت با قابلیت:

- 🎮 بازی تک‌نفره
- 🏠 ساخت اتاق آنلاین
- 👥 بازی چندنفره
- 🎡 انتخاب تصادفی جرئت یا حقیقت
- 🏆 جدول امتیازات
- ✏️ تغییر نام مستعار
- 🔄 اجرای Long Polling
- 🌐 قابلیت اجرا روی Render

---

## 🚀 نصب روی Render

### 1. ساخت Repository در GitHub

یک Repository جدید بسازید و این فایل‌ها را داخل آن قرار دهید:

```text
main.py
requirements.txt
.gitignore
README.md
```

---

### 2. ساخت Web Service در Render

در Render:

1. روی New + کلیک کنید.
2. گزینه Web Service را انتخاب کنید.
3. Repository GitHub را متصل کنید.

تنظیمات:

**Build Command:**

```text
pip install -r requirements.txt
```

**Start Command:**

```text
python main.py
```

---

## 🔐 تنظیم توکن ربات

توکن را داخل کد قرار ندهید.

در Render به بخش:

```text
Environment Variables
```

بروید و متغیر زیر را اضافه کنید:

```text
BOT_TOKEN
```

مقدار آن باید توکن واقعی ربات بله باشد.

---

## ⚠️ نکته مهم

اطلاعات کاربران و امتیازات در نسخه فعلی داخل حافظه ذخیره می‌شوند.

بنابراین در صورت Restart شدن سرویس Render، اطلاعات زیر پاک می‌شوند:

- نام کاربران
- امتیازات
- اتاق‌ها
- وضعیت بازی

برای دائمی شدن اطلاعات می‌توان از یک دیتابیس مانند PostgreSQL استفاده کرد.
